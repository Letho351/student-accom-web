# Student Accommodation Backend

Backend API for a student accommodation platform.
Handles property listings, student inquiries, uploads, and admin logic.

## Tech Stack
- Node.js
- Express
- MySQL
- Multer

## Features
- Student inquiry submission
- Property management
- File uploads
- Admin routes

## Environment Variables
Create a `.env` file with:
- PORT
- MySQL_URI

## Run Locally
npm install
npm run start
